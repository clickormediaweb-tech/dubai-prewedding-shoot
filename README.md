
# Dubai Pre-Wedding Shoots 🇦🇪💍

A high-end, responsive web application built for cinematic pre-wedding photography services in Dubai. It features a stunning glassmorphism interface, real-time admin panel controls, and seamless local data synchronization.

## ✨ Key Features
- *Cinematic Hero & UI:* Immersive layout featuring Google Fonts (Playfair Display & Lato) and modern glassmorphism styling.
- *Admin Control Panel (admin.html):* Manage background images, location cards, and preview customer bookings in real-time.
- *Interactive Booking System:* Clients can select dates, locations, and packages, with data automatically synced to localStorage.
- *Infinite Auto-Scrolling Gallery:* Smooth, continuous CSS-animated photo streams with interactive modal popups.
- *Fully Responsive:* Optimized for desktops, tablets, and mobile screens.
